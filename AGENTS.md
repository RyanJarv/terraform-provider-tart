# Workspace instructions

Existing tools and dependencies may be used when they are already set up and used by the project.

If installing a tool or adding, changing, downloading, or installing a dependency would help, stop and ask the user for explicit approval before proceeding. Give the exact package, module, or tool name, the pinned version, and its source URI. Explain why it is needed and where it would be installed or cached. This applies to host and guest environments, temporary installations and caches, transitive dependencies, package or plugin setup, manifest or lockfile changes, and upgrades. Tool approval and automatic approval do not substitute for the user's explicit permission.
